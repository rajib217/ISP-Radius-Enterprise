The modem is set up and switched on in Settings > bKash SMS auto-renew. It sends at most 10 SMS a minute (fewer if SMS per minute below is lower), Bangla too; a long message goes as several SMS. Your operator charges each SMS to the SIM, and sending many SMS from one SIM can get it barred: for large bulk messages an SMS provider is the better road.

HTTP gateway

Copy the sending address from your provider and put {to} and {message} where the number and text go. {sender} is also available. Values are URL-encoded for you.
Start with { to send JSON, otherwise it is sent as a form (a=b&c=d).
If set, the reply from the gateway must contain this text, or the message counts as failed. Leave empty to accept any 2xx reply.
