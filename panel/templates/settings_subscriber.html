Duplicate phone, duplicate NID/NIC and Identity Optional are checked whenever a subscriber is added or edited. They are lenient by default so existing customers can still be edited. Document upload off closes uploads on the Documents page.

{{ icon('user') }}Subscriber ID

Letters only. Shown before every subscriber's ID number in the list, the profile, the customer portal and the expired page, and sent to bKash as the reference. Customers may write it either way (RN05, rn5 or 5) in a bKash reference. Empty = the plain number.
Examples
RNRN01, RN02 ... RN125
empty1, 2 ... 125
